# M5Pet

M5StickC Plus2 を「デスクの上のペット」にする Arduino スケッチです。

電源を入れると、まるごとのリンゴが浮かび上がり → ピンクの丸いキャラクターが右から跳ねて登場 → リンゴを一口かじって → もぐもぐ噛んで → 満足そうな顔をして → 右へ去っていく → かじられたリンゴが白く発光 → フェードアウト → **画面いっぱいの2つの目**になり、あとは自分で勝手にあちこちを見つめ続けます。

本体を傾けると、目は傾けた方向を見ます。

## 動作環境

| 項目 | 内容 |
| --- | --- |
| ボード | M5StickC Plus2（`m5stack:esp32:m5stack_stickc_plus2`） |
| ライブラリ | [M5Unified](https://github.com/m5stack/M5Unified)（M5GFX を含む） |
| 画面 | 240 × 135（横向き） |
| フレームレート | 30 fps |

## 書き込み方法

1. Arduino IDE に M5Stack のボードマネージャ URL を追加し、`M5StickC Plus2` を選択
2. ライブラリマネージャから **M5Unified** をインストール
3. このリポジトリを `M5Pet` というフォルダ名のまま開き、`M5Pet.ino` をコンパイル → 書き込み

## ボタン操作

| ボタン | 起動アニメ中 | 目の画面 |
| --- | --- | --- |
| **A** | イントロをスキップ | 目をびっくりさせる |
| **B** | イントロをスキップ | 眠気タイマーをリセット（目を覚まさせる） |

25 秒ほど何もしないと、目はだんだん眠そうになります（`EYE_SLEEPY_AFTER_MS`）。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `M5Pet.ino` | エントリポイント。オフスクリーンバッファ（`M5Canvas`）の確保と、`BOOT` / `EYES` の状態遷移＋フレーム制御 |
| `Config.h` | 画面・配色・レイアウト・IMU の調整値をすべて集約。**まずここを触ると見た目が変わります** |
| `PetState.h` / `.cpp` | アプリの状態管理と、全体で共有する数学ヘルパー（イージング、スムージング、バネ、乱数、色ブレンド） |
| `BootAnimation.h` / `.cpp` | 起動アニメーション（11 フェーズのステートマシン） |
| `Eyes.h` / `.cpp` | 目の描画と挙動（視線・まばたき・表情・IMU） |
| `AppleBitmap.h` | リンゴのシルエット（1bpp ビットマップ） |
| `tools/gen_apple.py` | 元画像から `AppleBitmap.h` を生成する Python スクリプト（PIL 使用） |
| `references/` | 元絵とプレビュー画像 |

## 実装のポイント

### すべて「現在値 / 目標値」のペアで動く

`Eyes` の見た目のパラメータ（目の幅・高さ・瞳の大きさ・開き具合・視線 XY・口角）は、すべて `current◯◯` と `target◯◯` の対になっています。振る舞いのレイヤー（視線スケジューラ、まばたき、表情、IMU）は **目標値だけ** を書き換え、現在値が毎フレームそれを追いかけます。そのため値が突然飛ぶことがなく、常になめらかに動きます。

サイズ系のチャンネルだけはバネ（`springTowards`）で追従するので少し行き過ぎ、それが「びっくり」のポンという動きや、平常に戻るときの生っぽさになっています。

### リンゴのかじり跡は画像ではなく「円」

かじられたリンゴは 2 枚目の素材ではありません。`references/apple_bitten.png` にサブピクセル精度でフィッティングした**円のマスク**で、その半径を 0 から最大までアニメーションさせています。だから同じ 1 枚のビットマップから「かじる前」「かじり途中」「かじった後」がすべて描けます。

### ブロッキングしない

`loop()` の中に長い `delay()` は一切ありません。`millis()` との差分でフレームを刻み、時間が来ていなければ `delay(1)` して即 return します。

### IMU から視線へ

加速度センサの傾きが `IMU_TAKEOVER`（0.40）を超えると視線の主導権を IMU が奪い、`IMU_RELEASE`（0.18）を下回って一定時間（1.2 秒）落ち着いたら自動の視線スケジューラに戻します。

> 目が逆方向を向く場合は `Config.h` の `IMU_SIGN_X` / `IMU_SIGN_Y` の符号を反転、軸が入れ替わっている感じがする場合は `IMU_SWAP_AXES` を `true` にしてください。

## カスタマイズ

`Config.h` の主な調整項目：

```cpp
static const uint8_t  SCREEN_BRIGHTNESS   = 110;    // 画面の明るさ
static const uint32_t TARGET_FPS          = 30;     // フレームレート
static const uint16_t COL_CHAR_BODY       = rgb565(255, 166, 196);  // キャラの体色
static const int      EYE_BASE_W          = 84;     // 目の基本サイズ
static const uint32_t EYE_SLEEPY_AFTER_MS = 25000;  // 眠くなるまでの時間
static const float    IMU_GAIN            = 2.4f;   // 傾きに対する視線の反応量
```
